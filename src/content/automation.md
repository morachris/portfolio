## Goal
---

* **Educational Focus:** Reinforce OOP fundamentals through guided learning modules.
* **Theory + Practice Approach:** Combine conceptual explanations with practical exercises to improve comprehension.
* **Student-Centered Design:** Adapted to the academic level and learning needs of technical high school students.


## Tech Stack
---
The project was implemented as a full-stack web application, prioritizing simplicity, clarity, and maintainability to support its educational purpose.

### Technical Specifications
| Category | Technology | Usage |
| :--- | :--- | :--- |
| **Frontend** | React | User interface and interaction logic |
| **Backend** | Node.js (Express) | Application logic and content delivery |
| **Database** | MySQL (mysql2) | Persistent data storage for user data and progress |
| **Content Format** | Markdown | Structured theoretical lessons |
| **Architecture** | Monolithic | Unified academic application structure |

### Infrastructure & Tooling
* **Development Environment:** Local development setup for academic use.
* **Version Control:** Git for tracking changes and managing the project repository.


## Key Highlights
---
### 1. Modular Learning Structure
The application is organized into progressive learning modules, starting from **basic concepts such as classes and objects** and advancing toward a detailed explanation of the **four pillars of Object-Oriented Programming**:
- Abstraction
- Encapsulation
- Inheritance
- Polymorphism

> **Note:** Each module builds upon the previous one, reinforcing knowledge incrementally in an academic context.

### 2. Theory and Practice Integration
* **Theoretical Content:** Written using Markdown to ensure clarity and easy readability for students.
* **Practical Exercises:** Each module includes exercises designed to apply the concepts learned.
* **Comprehensive Evaluation:** A final section with **16 cumulative exercises** evaluates overall understanding.

In total, the application contains **34 different exercises**, covering both conceptual knowledge and practical application.

### 3. Academic Scope and Limitations
This project was developed exclusively for educational purposes within a controlled academic environment. Design decisions prioritized learning effectiveness over scalability or production-level optimization.

The application serves as a ***learning support tool***, not as a commercial or enterprise-grade system.
